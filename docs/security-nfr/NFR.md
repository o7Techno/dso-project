# Security NFRs — Event Planner

| ID     | Название                   | Описание                                             | Метрика/Порог                  | Проверка              | Компонент      | Приоритет |
|--------|-----------------------------|------------------------------------------------------|--------------------------------|----------------------------|----------------|-----------|
| 1 | Безопасное хранение паролей | Пароли не должны храниться в открытом виде           | Argon2id или bcrypt            | Код + тест регистрации     | Auth           | High      |
| 2 | Срок жизни сессии/токена    | Сессия пользователя должна автоматически истекать    | <= 30 минут                     | Unit-тест, проверка в коде | Auth           | High      |
| 3 | Доступ к событиям           | Пользователь может видеть только свои события        | 100% проверок                  | API тесты                  | Events CRUD    | High      |
| 4 | Валидация дат               | Нельзя создать событие в прошлом                     | Дата >= now()                   | Pytest                     | Events CRUD    | High      |
| 5 | Дубликаты событий           | Нельзя создать одинаковое событие (title+date+place) | Дубликаты = 0                  | DB constraint + тест       | Events CRUD    | Medium    |
| 6 | Устойчивость к ошибкам API  | Запросы во внешние сервисы должны иметь таймаут      | Таймаут <= 5 сек, 2 ретрая макс | Integration тест           | Calendar API   | Medium    |
| 7 | Логи CRUD                   | Все изменения событий пишутся в лог                  | Лог >=s 1 запись на действие     | Проверка логов             | Events CRUD    | Low       |
| 8 | Актуальные зависимости      | Используются только поддерживаемые версии пакетов    | Нет зависимостей с CVE High    | `pip-audit` или аналог     | Backend        | Medium    |
